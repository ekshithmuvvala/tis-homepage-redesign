# Tulas International School — Homepage Redesign

A modern, responsive homepage redesign for Tulas International School built as a frontend development assessment project.

## Live Demo

https://tis-homepage-redesign.vercel.app

## Tech Stack

- Next.js
- React
- TypeScript
- Tailwind CSS
- Framer Motion
- Lucide React

## Features

- Responsive single-page school homepage
- Animated hero section
- Scroll-triggered reveal animations
- Custom cursor interaction
- Scroll progress indicator
- Light and dark theme switcher
- Responsive navigation
- Admissions call-to-action
- Campus showcase
- Mobile-friendly layout
